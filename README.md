# Algorithmic Amplification and YouTube Comment Sentiment Analysis

An end-to-end reproducible R data science project analyzing sentiment dynamics and algorithmic amplification patterns in YouTube comment datasets (N = 20,000).

## Repo Structure

algo_amp_yt_comm:

dataset:
	YouTube Comments Sentiment 20000 CSV.csv
	yt_comm_codebook.txt
 
code+nb:
	algo_amp_yt_comm_nb.qmd

install_deps.txt
LICENSE
README.md
.gitignore

## Environment & Requirements
R Version: 4.5.2

Required R Packages: tidyverse (ggplot2, dplyr, tidyr, stringr), scales, broom, infer, effects, rstatix, ggpubr, boot

## Installation

Clone the repo:

git clone git@github.com:nshpaner/algo-amp-youtube-comment-analysis.git

cd algo-amp-youtube-comment-analysis
